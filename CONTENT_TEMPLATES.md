## 📝 Form Field Templates

### Contact Form
```
Fields:
• Full Name * (required)
• Email Address * (required)
• Company Name (optional)
• Phone Number (optional)
• Industry (dropdown: Medical Devices, Pharmaceutical, Gloves, FMCG, Other)
• Message * (required, 500 characters max)

Validation:
• Name: Required, min 2 characters
• Email: Required, valid email format
• Company: Optional, max 100 characters
• Phone: Optional, 10-15 digits
• Industry: Required, default to first option
• Message: Required, min 10 characters, max 500 characters

Messages:
• Success: "Thank you for your message! We will get back to you within 24-48 hours."
• Error: "Sorry, there was an error sending your message. Please try again."
• Validation: "Please fill in all required fields correctly."
```

### Newsletter Form
```
Fields:
• Email Address * (required)

Validation:
• Email: Required, valid email format, not already subscribed

Messages:
• Success: "Thank you for subscribing to our newsletter! You'll receive updates at {email}."
• Error: "This email is already subscribed."
• Already Subscribed: "You are already subscribed to our newsletter."
```

## 📸 Image Guidelines

### Image Sizes
```
Logo: 300x300px (PNG with transparency)
Hero Background: 1920x1080px (JPG or WebP)
Facility Photos: 1600x1200px (JPG or WebP)
Product Photos: 1200x800px (JPG or WebP)
Team Photos: 400x400px (JPG or PNG)
Favicon: 32x32px (ICO)
Apple Touch Icon: 180x180px (PNG)
```

### Image Formats
- [ ] PNG for transparent images (logo, icons)
- [ ] JPG for photos
- [ ] WebP for optimized images (recommended)
- [ ] SVG for scalable graphics

### Image Naming
```
Format: [description]-[type]-[version].[ext]
Example: case-packer-1-optimized.webp
```

### Alt Text Guidelines
```
Format: Brief description of image
Length: Max 125 characters
Example: "Automatic case packing machine in pharmaceutical manufacturing facility"
```

## 📝 Blog Post Templates

### Blog Post Title
```
Format: [Catchy Title] - [Context]
Length: 50-70 characters
Example: Case Study: How PacTech Increased Throughput by 40%
```

### Blog Post Meta
```
Author: [Author Name]
Date: [Month Day, Year]
Category: [Industry Trends, Product Updates, Case Studies, Technical]
Read Time: [X] minutes
Tags: [tag1, tag2, tag3]
```

### Blog Post Structure
```
1. Headline
2. Meta Information (Author, Date, Category, Read Time)
3. Featured Image
4. Introduction (150-200 words)
5. Body Paragraphs (3-5 sections)
6. Key Takeaways (3-4 bullet points)
7. CTA (Call to Action)
8. Tags
9. Related Posts (3-5 links)
```

### Example:
```
Headline: Case Study: How PacTech Increased Throughput by 40%

Meta:
Author: Ahmad Razak
Date: March 1, 2026
Category: Case Studies
Read Time: 6 minutes
Tags: case study, automation, manufacturing, case packing

Introduction:
Medical device manufacturers face unique challenges in packaging sterile equipment while maintaining strict quality standards. This case study examines how PacTech's custom solution addressed these challenges.

Body:
[3-5 sections of detailed information]

Key Takeaways:
• Custom automation systems outperform standard solutions
• Vision inspection improves quality by 99.8%
• ROI achieved in 12 months

CTA: Ready to transform your packaging operations? Contact us today!

Tags: case study, automation, manufacturing, case packing

Related Posts:
```
